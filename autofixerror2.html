PRIVACY POLICY

      
    
        
  • Zero upload. Everything you paste is processed in this tab's memory only. The page declares connect-src 'none' in its Content-Security-Policy — the browser itself forbids any network request this page could make. There is no backend to send it to.
    • 
        
  • No cookies, no analytics, no telemetry, no fingerprinting. Nothing is written to localStorage or indexedDB. Close the tab and your code is gone.
    • 
        
  • Clipboard & downloads are user-initiated only, and only ever contain the code you pasted (after it passed verification).
    • 
        
  • Referrer is suppressed (no-referrer) so third parties can't learn you visited via a referring page.
    • 
        
  • Advice: never paste real credentials, API keys or private keys anywhere — this tool detects them and blocks copying until they're scrubbed, but the safest secret is one that was never pasted.
    • 
      

    

    

      
SECURITY POLICY

      
    
        
  • Content-Security-Policy: default-src 'none'; scripts limited to self + pinned CDNs (unpkg, jsdelivr); styles/fonts limited to Google Fonts; connect-src / object-src / frame-src / form-action / base-uri: none. Because this is a static file, the policy ships via <meta> — if you host it (e.g. GitHub Pages), also send real CSP headers where possible, including frame-ancestors (header-only).
    • 
        
  • No execution of your code — guaranteed by construction. This page contains no eval and no new Function. Your code is only ever parsed (acorn for JS, a hand-built Java grammar, JSON.parse, DOMParser, structural scanners). Parsing does not run code.
    • 
        
  • Supply chain: the single third-party script (acorn) is version-pinned across two CDNs with automatic fallback. For production, add Subresource Integrity (integrity="sha384-…", generated with openssl dgst -sha384 -binary … | openssl base64 -A) — deliberately not shipped without a verified hash.
    • 
        
  • Anti-hijacking / anti-cloning / anti-mirroring: standalone and benign local/same-origin embeds pass silently. Unknown cross-origin embeds show a visible, dismissible warning while the app keeps working — the honest design, since client-side detection cannot reliably distinguish your IDE preview from a mirror, and a real cloner strips scripts anyway. A MutationObserver removes any script/iframe/object/embed/link injected into the DOM after load. Oracle tables are Object.freezed against runtime tampering.
    • 
        
  • Injection hardening: every dynamic render passes through an HTML escaper; downloads use a fixed whitelisted filename; the textarea opts out of browser autofill/autocorrect.
    • 
        
  • Self-XSS warning: the console warns you never to paste code someone told you to paste — that is a classic social-engineering scam.
    • 
        
  • Honest limits: heuristics can false-positive; client-side protection cannot stop a determined scraper of rendered output (there is nothing sensitive here to scrape); meta-CSP is weaker than header CSP. Remedies noted above.
    • 
      

    

    

      
ANTI-MALVERTISING & ACCEPTABLE USE

      
    
        
  • No ads, ever. No ad scripts, no trackers, no third-party beacons — enforced by CSP. Better Ads Standards are met vacuously: nothing commercial is served.
    • 
        
  • No deceptive patterns: no forced downloads, no auto-redirects, no fake buttons, no countdown walls, no notification prompts. Downloads and clipboard writes happen only on your explicit click.
    • 
        
  • Paste-time malware screening: input is heuristically screened for common malicious families — cryptominers, eval/decode execution chains, webhook & cookie exfiltration, keyloggers, reverse shells, PHP webshells, obfuscated payloads, DGA-style domains, clickjacking overlays, tabnabbing, SQL/XSS/command-injection payloads, and leaked secrets. Malicious-level results are quarantined: copying stays locked until SANITIZE neutralizes the flagged constructs live (commenting first, removing stubborn lines second — every step re-scanned and logged).
    • 
        
  • Acceptable use: this is a repair tool for your own code. You may not use it to develop, harden, or launder malware. Findings are heuristic signals, not legal or forensic verdicts — false positives are possible and every match is shown with its rule and line so you can judge.
    • 
        
  • Disclosure: if you embed or mirror this tool, you must preserve this policy panel, the CSP, and the frame banner. Stripping them to silently mirror the tool is a violation.
